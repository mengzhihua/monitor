# 个人 AI 分析

桌面 Web 与手机 H5 共用此能力，无需单独部署前端。升级包含本更新的服务端包，或运行 `make all` 后启动。默认未配置模型；日常看板不会自动调用 AI，也不会新增后台分析任务。

## 使用方式

1. 登录后，桌面打开工具栏的 **AI 分析**；手机打开 **更多 → AI 分析**。
2. 在个人配置中填写 **API Base URL**、**模型名称**和自己的 **API Key**，保存。
3. 选择当前节点的 1–6 张图表、最近 1 分钟至 24 小时的统计窗口，点击生成数据预览。预览只读取本服务数据，此时不联系模型。
4. 核对预览统计、缺失数据、相关告警和完整 JSON，填写问题后点击发送分析。请求包含监控主机名及所选指标名称、统计值，请使用自己信任的模型服务。
5. 结果以纯文本展示，可复制或下载包含问题、模型、快照与结果的文本报告。模型建议需要人工核实，系统不会执行命令或修改告警规则。

修改图表、节点、时间窗口或配置会使旧预览和结果失效。每个账号只保留最新预览，有效期 5 分钟，最多发送一次；失败或取消后也需要重新生成，避免重复调用产生费用。取消能停止本服务等待，但模型服务可能已处理请求，费用以服务商记录为准。

## 接入模型

| 字段 | 填写说明 |
| --- | --- |
| API Base URL | API 根地址，例如 `https://api.openai.com/v1`；不要填写完整的 `/chat/completions` 路径 |
| 模型 | 服务商提供且当前账号有权调用的准确模型 ID，最多 128 字节 |
| API Key | 可选；需认证的服务必须填写有效密钥。保存后只显示是否已配置，不回显原值 |
| 允许私有地址 | 仅管理员可开启，允许连接本地或私有网段模型；此选项属于当前账号配置 |

服务端向 `Base URL + /chat/completions` 发送 `model`、`messages`，读取 `choices[0].message.content` 文本与可选 token 用量。协议参考 [OpenAI Chat Completions 接口](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。不支持仅有 Responses、流式返回、工具调用或非文本回答的接口；“兼容 OpenAI”仍需要服务商实际支持上述字段和模型。

管理员可将 Base URL 配为例如 `http://127.0.0.1:11434/v1` 并启用私有地址，前提是该端口实际运行兼容服务。模型连接由 **monitord 所在服务器** 发起，所以这里的 `127.0.0.1` 指服务器，不是访问 H5 的手机。公共服务必须使用 HTTPS；HTTP 只允许明确授权的私有地址。不跟随重定向，不使用环境代理，不自动重试；DNS 解析结果在连接前校验并固定，链路本地、组播和实现中列出的保留网段仍被阻止。该校验按地址范围工作，并不识别所有云厂商的元数据服务；启用私有地址时，管理员应只配置可信模型端点。

修改已有密钥配置的 Base URL 时，必须重新输入密钥或选择清除旧密钥，防止把旧服务商凭据带到新地址。多个设备同时修改会提示版本冲突，保留本地草稿，可读取最新版本后核对保存。取消保存或删除时，修改可能已经到达服务器，界面会要求先重新读取最新配置再继续。

## 发送数据与统计含义

发送的快照固定为预览时的数据，发送时不重新查询，包含：

- 当前节点 ID、主机名、统计起止时间及生成时间。
- 1–6 张选中图表的标题、单位、采集间隔；每张最多 32 个可见维度。
- 约 120 个时间桶的均值汇总：有效与缺失桶数、桶均值的最小/最大/平均、首个和最后一个有效桶值。
- 所选图表当前相关告警，最多 50 条；节点状态和截断等说明。

时间网格对齐后可能有 121 个桶。`last_at` 是有效桶结束时间，末桶截止于快照时间，**不是原始样本时间**。首末值跳过缺失桶；桶间缺失不填零。聚合统计不能用来声称原始瞬时峰值，也不能仅凭趋势认定根因。原始 JSON 同时提供步长、有效桶数和缺失桶数供核对。

快照不包含日志、配置文件、主机/图表标签、处置备注或凭据；用户输入的问题也会发送给模型。快照 JSON 最大 64 KiB，问题最多 2,000 个 Unicode 字符。历史支持本机与 Hub 直接连接且已保存历史的节点；Hub 代理存储与跨集群转发节点暂不支持此分析入口。权限在生成预览及发送时分别校验。

## 身份与保存

配置按登录身份存放，与个人视图使用相同身份原则：共享同一凭据的用户共享同一配置；相同显示名但不同凭据不会互通。静态密码或 API token 轮换后进入新的配置空间；身份认证使用经过验证的身份主体。只读账号可以管理自己的公共模型配置与分析，原有监控修改权限保持有效。匿名访问和分享链接不能使用个人 AI 接口。

真实服务端将配置保存到 `<data_dir>/operations/ai-settings.json`，使用原子替换，Unix 文件权限为 `0600`，重启后保留。文件包含调用所需的密钥，**未进行额外静态加密**；部署账号、Windows 目录 ACL 和备份应按凭据文件管理。密钥不写入浏览器持久存储，不在 API 响应或模型错误中返回。删除配置清除当前配置文件中的密钥，但不会删除操作系统、文件系统或管理员另存的备份。

每个服务最多保存 256 个身份记录（含保留版本的删除记录），文件最大 2 MiB；嵌入式 API 未配置 OperationsDir 时仅内存保存，界面会提示重启丢失。模型分析结果与预览不持久化；下载报告由用户自行保管。若配置文件损坏，服务启动报错；写入后目录同步失败则配置服务暂停使用，重启重读磁盘状态后恢复，不接受可能覆盖新版本的旧写入。

## 资源限制与排错

数据预览与模型调用各自限制为每账号同时 1 个、全服务同时 2 个请求，超过立即返回 429。预览缓存最多 256 份。模型请求最长 60 秒，响应体最大 256 KiB，显示文本最大 64 KiB，超过文本上限会提示截断。没有默认自动重试或定时调用。

| 提示 | 处理方式 |
| --- | --- |
| 配置或快照冲突（409） | 读取最新配置，核对草稿，重新生成预览；过期或已使用快照不能再次发送 |
| 请求过于频繁或额度不足（429） | 等待已有请求结束，或检查模型服务额度，再手动生成预览重试 |
| 无权访问（403） | 检查登录身份、节点机房范围和私有模型权限 |
| 模型连接/响应失败（502） | 检查服务器能否访问 Base URL，以及模型名、密钥和协议兼容性 |
| 超时（504） | 检查模型负载和网络，服务不会自动重试 |
| 配置服务不可用（503） | 检查数据目录权限与磁盘状态；同步失败后先恢复存储，再重启服务 |
