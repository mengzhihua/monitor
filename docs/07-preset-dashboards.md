样板目录支持「通用巡检」「数据服务」「应用与中间件」「基础设施」「运维值班」「平台服务」「操作系统」分类与名称/场景搜索。每个卡片标注当前节点已采集的指标类别数量；匹配到图表不代表服务健康或数据新鲜。目录筛选独立于顶部图表筛选，不会改变正在查看的看板。没有匹配结果时可以一键清除样板筛选。

看板按当前节点实际返回的 chart context 自动匹配，缺少 context 时使用 chart ID。Hub 切换节点后跟随当前节点；顶部筛选、时间范围、实时更新和图表过期提示与原看板一致。默认每组展示优先级最高的四张图，更多实例可展开。全部指标入口保留原有分类浏览。

这些样板聚合展示已有图表，不把不同单位的数值相加，不生成业务成功率或 P95，也不自动判断发布成败。尚未采集的指标会显示缺失说明，接入数据后自动出现。看板无需配置不意味着能够跳过数据库凭据、HTTP 目标等采集前提；采集由现有采集器设置控制。

定义位于 `web/src/dashboards.ts`，展示组件为 `web/src/components/DashboardsPanel.vue`。

运维场景附三步排查建议，调研依据与能力边界见 [运维看板调研](08-operations-dashboard-research.md)。

平台服务样板同样提供三步排查建议。虚拟化平台、网络设备和远程服务的指标对象可能不同于采集节点；应根据图表实例及名称确认归属。VPN 空闲握手、邮件队列数量、认证指标不能单独作为离线、投递成功或攻击判定。未连接真实服务时只验证图表匹配及缺失数据展示。

专项看板按各自服务前缀匹配，避免将其他数据库、缓存或设备混入主分组。nftables 和 Fail2ban 仅展示计数与封禁情况，不提供攻击判定；IPMI / Redfish 的远程服务器身份应结合采集目标确认。

操作系统样板直接匹配该平台已有指标，不推断当前节点的操作系统。Windows 依赖对应计数器，macOS 部分采样依赖硬件和权限，Android 仅覆盖已接入应用使用样本。DHCP 的范围/主机计数不表示地址池余量；无线平均信号不表示所有客户端体验。


新增样板：云平台指标汇总（CloudWatch / Azure Monitor）、CouchDB / Couchbase 文档库、打印服务巡检（CUPS）、登录会话巡检（logind）。云平台通用 value 单位需核对采集配置，不推算成本；打印任务计数不证明实际出纸；会话计数不代替登录审计。

## Web 个人看板配置

点击「新建看板」，或将当前样板「复制为个人看板」。填写名称后选择自动匹配的指标分组，也可选择当前节点的具体图表；上移、下移和移除按钮调整展示顺序。指定图表独立放在最后一组，按保存顺序展示，可能与自动分组重复。未采集的指定 ID 会保留，编辑器会标注缺失。

可设置独立时间范围（默认跟随顶部时间）、自适应或 1–3 列布局、每组默认 2/4/8/12 张图，以及隐藏未采集分组。窄屏自动减少列数，更多图表仍可展开。分组和具体图表配置跟随当前节点匹配，不把图表绑定到原节点。

「我的看板」分类集中展示个人配置，可编辑或确认删除。「收起样板目录」用于腾出图表空间。编辑时切换其他样板不会修改正在编辑的配置，取消编辑不保存。

配置保存在当前站点、当前浏览器的 localStorage（`monitor.personal-dashboards.v1`），不是服务端账号配置，不会自动跨设备同步。共享浏览器的使用者可以看到配置；清理浏览器数据会删除配置。请用「导出个人看板」备份 JSON，通过「导入为副本」迁移。导出只包含个人看板配置，不包含采集数据或认证令牌。最多 20 个个人看板，每个最多 30 个分组和 100 个指定图表；配置总大小及导入文件上限 500 KB，版本为 1，格式、分组和参数必须通过校验，失败不会部分导入。存储不可用时会显示保存失败并保留编辑内容。

导入先显示预览，可核对文件名、每个看板的内容、时间和布局设置，以及当前节点可匹配的图表数，再勾选需要的看板并点击「确认导入所选看板」。未确认或取消时不写入配置；同名看板也会创建新副本。页面显示剩余容量，保存时再次检查最新配置；超限或写入失败会保留预览与选择，未采集的指定图表 ID 不会丢失。完整流程见 [Web 看板更新说明](09-dashboard-final-update.md)。

## 中文指标说明

全部指标、内置样板和个人看板共用中文说明：鼠标悬浮图表标题或指标 ID 可查看含义和阅读提示，悬浮单位可查看中文量纲，悬浮图例名称或数值可查看对应维度说明。堆叠图的图例说明按照实际序列顺序匹配，自身数值与累计图形高度有明确区分。

每张图还提供「中文指标说明」折叠入口，支持点击、触屏及键盘 Enter 展开，包含图表和全部可见维度说明。常用系统指标有专用解释，其他已知服务引用对应指标组的中文阅读提示；未知自定义指标保留原始名称、单位和采样间隔，明确提示尚无专用释义，不猜测状态编码或健康阈值。说明映射位于 `web/src/metricHelp.ts`，不改变原始采样或数值。

## 收藏、导航与多标签页编辑

- 「收藏当前看板」将内置或个人看板加入「收藏」分类。再次进入聚合看板会恢复上次选择和目录展开状态；这些偏好保存在当前浏览器，不随个人看板 JSON 导出。
- 「仅看主分组已采集的样板」按每张看板的第一个指标组筛选。例如 MySQL 专项仅有主机内存数据时不会入选。此筛选只说明存在图表定义，不证明数据新鲜或服务健康；个人看板可通过调整分组顺序决定主要指标。
- 分组导航可直接跳转并展开对应分组，支持键盘焦点。折叠分组会卸载其中图表并释放其订阅，再次展开时按当前节点与时间范围重新加载。分组折叠状态仅对本次查看生效。
- 同一浏览器其他标签页的个人看板变动会同步到目录，已经打开的编辑草稿不会被替换。保存前重新读取存储，并检查该看板是否与开始编辑时一致；检测到修改或删除时拒绝覆盖，可「另存为新看板」或取消后重新编辑。删除操作同样检查版本，其他看板的变动会被保留。这是本地配置冲突检查，不提供跨设备协作或服务端事务保证。
- 正在编辑时，新建、复制、再次编辑、删除和导入入口暂时禁用，避免替换当前草稿；保存错误就近显示在编辑器底部。有待恢复草稿时，新建、复制和编辑入口也会暂时禁用，可先恢复或丢弃草稿。
- 配置损坏时不会自动覆盖原始数据，内置样板仍可使用。请先备份浏览器中的原始配置再修复；合法 JSON 导入仍作为副本处理。

目录覆盖率、主要指标筛选和当前看板共用按分组计算的匹配结果；不会为每个重复引用该分组的样板重新扫描所有图表。

## 编辑草稿恢复

编辑内容自动暂存到当前标签页的 sessionStorage（`monitor.dashboard-draft.v1`），未填写名称或尚未选择指标也可以暂存。刷新页面、切换运维总览或全部指标后返回聚合看板，会出现「恢复草稿」和「丢弃草稿」入口。恢复不等于正式保存；点击「保存看板」后才会加入个人看板。保存成功、取消编辑或丢弃草稿会清除暂存内容。

草稿同时保留开始编辑时的正式配置，恢复后保存仍会检查其他标签页是否修改或删除了原看板。冲突时可另存为新看板，避免覆盖新版本。草稿不跨标签页同步，关闭标签页、清理浏览器数据可能使其丢失；存储不可用或内容无法校验时会显示提示，请及时正式保存或导出配置备份。

## 图表放大与数据导出

全部指标、内置样板和个人看板中的图表均提供「放大图表」和「导出 CSV」。放大窗口沿用当前节点、时间范围和中文说明，并随窗口宽度调整图形；原卡片在放大期间暂停自身更新，关闭后恢复。支持关闭按钮和 Esc，关闭时焦点返回原放大按钮。

CSV 包含节点 ID、图表 ID、UTC 时间、Unix 时间和各维度的原始单位，只导出当前已加载的采样；长时间范围可能是聚合采样，不代表完整原始历史。堆叠图导出每个维度自身的值，不导出累计高度。缺失或非有限值留空，真实的 0 和负数保留。尚未加载、加载失败或没有采样时不能导出。图表名称和维度等文本按 CSV 规则转义，避免电子表格将其识别为公式。Hub 切换节点会重建同 ID 图表，避免混用前一节点数据。

## 固定历史时段与采样统计

放大图表后可「固定当前时间」，或输入本地结束时间并点击「查看该时段」。时长沿用看板当前时间范围；「上一时段」「下一时段」按该时长平移，下一时段不会超过当前时间。无效日期、未来时间或早于 Unix 纪元的范围会被拒绝，保留原查询。「返回实时」恢复跟随当前时间；该设置只作用于本次放大查看，关闭后不会改变看板配置。

固定时段使用绝对起止时间查询，停止实时订阅和定时刷新；隐藏后再次显示仍查询同一时段。历史图不显示当前异常标记和实时过期提示，因为现有异常元数据不能代表所选历史时段的状态。切换时段会清除原曲线，加载失败会提示并允许重试，避免将旧数据误当成新查询结果；无采样时说明可能超出采集或保留范围。

放大视图按维度显示末行值、最小值、最大值、平均值和「非空采样数 / 总行数」。统计使用各维度自身的已加载数值，堆叠图不使用累计高度；忽略空值、NaN 和无限值，保留 0 和负数。末行缺失显示「—」，不向前填充。均值是已返回采样的算术平均，不是时间加权平均；长范围可能已聚合，因此这些统计不等于原始数据全量统计，非空采样比例也不代表服务可用率。窄屏统计表可横向滚动，列标题提供中文解释。

## 整个看板统一查看时间

「指标图表」工作区顶部提供统一时间控制。「冻结整个看板」以点击时刻作为所有图表的结束时间；也可以展开「设置历史时间」，输入本地日期时间后应用。历史模式使用醒目的提示，各图表显示「历史快照」及其起止时间悬浮说明。这里只固定查询时段，不保存不可变的数据副本；重新查询时可能读取到后来补齐的历史样本。

全部指标、内置样板和个人看板共用这一结束时刻，切换节点或展开更多图表后保持一致。顶部时长控制默认回看范围和前后翻页步长；个人看板的独立时长继续生效，因此各图表的开始时间可以不同。结束时间不足以容纳某个独立时长时，该图表明确报错，不会将负时间误作相对时间查询。

放大图表继承看板结束时间，放大窗口内的前后翻页只影响该窗口，关闭后回到看板统一时间。「整个看板返回实时」恢复跟随当前时间。告警、节点状态和运维总览始终是当前信息，不随历史图表冻结；从运维问题「定位图表」会自动返回实时并说明原因。

顶部时长与统一结束时间保存在当前标签页的 sessionStorage（`monitor.chart-timeline.v1`），刷新后恢复；不跨标签页或设备同步，不包含令牌，也不随个人看板 JSON 导出。损坏、超长或未来时间配置不会应用，页面会提示并回到实时模式，原始内容保留到用户主动更改查看时间。存储失败不阻止本次查看，并明确提示刷新后可能无法恢复。

## 相邻时段对比

放大图表后点击「对比上一时段」。如果正在实时查看，会先固定本次放大窗口的结束时间；不会改变整个看板的统一时间。对比当前时段与前一个相邻、等长的查询时段，使用相同节点、图表、查询点数上限和原始单位，按维度 ID 配对，不依赖返回顺序。返回实时会关闭对比；前后翻页会查询新的两段数据。

表格显示本段均值、前段均值、均值差值、相对变化率及两段各自的非空采样数 / 总行数。均值基于已返回的有限采样，堆叠图仍使用各维度自身数值；差值为本段减前段，变化率为差值除以前段均值再乘以 100%。前段均值为 0 或负数时只比较差值，不计算变化率；任一段无有效采样或数值溢出时显示「—」及原因，不把缺失当作 0。百分比指标的差值表示百分点，相对变化率仍是相对基准的比例；上升或下降不自动表示健康变好或变坏。

面板展示两段查询时间和接口实际返回的采样网格。长时段可能聚合，前段可能缺少早期采样，不同数量或精度的均值不能视为同等覆盖的全量统计。历史保留不足会明确提示，单位不一致时拒绝比较。对比查询按需发起，不额外轮询；关闭面板、切换时段或进入后台时取消未完成请求，过期响应不回填。对比失败可以单独重试，不影响本段曲线和本段 CSV。

「导出时段对比 CSV」包含节点、图表、单位、两段 UTC 边界、维度 ID、均值、差值、变化率及采样数量和原因。不可计算的数值留空，不包含令牌。维度名称等文本沿用公式转义保护。关闭放大窗口后按原看板时间继续查看。
