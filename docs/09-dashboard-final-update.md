# Web 看板收尾更新

本次更新收尾的是 Web 看板的日常查看、配置迁移与历史排查流程。整体版本保持 `2.0.0-dev`，不代表已发布全平台正式 `v2.0.0`。完整样板清单及指标阅读规则见[聚合看板说明](07-preset-dashboards.md)，运维问题处置与持久化规则见 [2.0 运维工作台](06-monitor-2.0.md)。

## 开箱查看与个人配置

「指标图表 → 常用聚合看板」提供 54 个内置样板，覆盖研发、运维值班、数据库、中间件、容器、网络、存储、硬件、云平台和操作系统。无需编写查询即可使用当前节点已采集的指标；数据库凭据、采集目标和权限仍需由采集器配置提供。缺失数据会明确提示，不把未采集当作正常。

目录支持分类、搜索、收藏、记住上次选择及收起目录。可以只显示主分组已采集的样板；匹配数量只说明存在图表定义，不代表服务健康或采样新鲜。分组导航可跳转并展开内容，折叠分组时释放其中图表资源。

个人看板支持从内置样板复制或新建，配置指标分组、指定图表与显示顺序、独立时间范围、自适应或 1–3 列布局、每组默认图表数及隐藏未采集分组。切换节点后按同一配置重新匹配，暂时缺失的指定图表 ID 继续保留。窄屏自动减少列数，统计和对比表格可横向滚动。

## 本次新增：导入预览与选择

1. 点击「导入为副本」并选择个人看板 JSON。文件校验成功后显示预览，尚未写入个人看板。
2. 核对文件名、看板名称和描述、分组及指定图表数量、当前节点匹配的图表数量，以及时间范围、列数和默认展示数量。
3. 勾选需要的看板，可全选或清空选择。页面显示已选择数量和剩余容量；没有选择或超过容量时不能确认。
4. 点击「确认导入所选看板」后保存独立副本。同名看板会提示，不覆盖已有配置；取消导入不会写入配置。

导入保留所选看板的描述、分组与指定图表顺序、时间范围及布局设置。当前节点缺少的图表不会被过滤掉；以后接入相应数据或切换节点后可自动匹配。导入会生成新 ID，配置迁移不包含采集数据、认证令牌、收藏或当前查看时间。

最多保留 20 个个人看板，每个最多 30 个分组和 100 个指定图表。文件和配置总大小分别限制为 500 KB，支持版本 1 格式。文件格式和参数先校验；确认保存前重新读取最新配置并校验合并后的容量，避免覆盖其他标签页期间新增的看板。超过容量、存储不可用或原有配置损坏时说明原因，不进行部分导入，也不自动清除原有配置。

个人看板在当前站点的浏览器 `localStorage` 中保存；导出 JSON 后可在另一个浏览器选择性导入。清理浏览器数据会删除本地配置，不提供服务端账号保存或自动跨设备同步。

## 数据一致性修复

- 图表查询会核对采样单位与图表定义。单位缺失或不一致时清除旧曲线和统计，暂停 CSV 导出及前后时段对比，显示中文错误并支持重试，避免将不同单位的数值进行比较。
- 浏览器无法保存节点选择时，当前节点仍完成切换并重新查询图表、告警和实时连接，同时提示刷新后可能无法记住选择，避免新节点标题下残留旧节点数据。

## 草稿恢复与编辑冲突

编辑内容暂存在当前标签页 `sessionStorage`。刷新页面或切换工作区后，返回聚合看板可恢复或丢弃草稿；恢复后仍需正式保存。关闭标签页或清理浏览器数据可能丢失草稿。

保存和删除前会核对该看板是否已被其他标签页修改或删除。发现冲突时保留草稿并拒绝覆盖，可另存为新看板。其他看板的变更会保留；该机制是浏览器本地冲突检查，不是跨设备协作或服务端事务。

## 中文说明与历史排查

图表标题、指标 ID、单位、图例和统计列提供中文悬浮说明；「中文指标说明」折叠区域也可通过触屏或键盘展开。未知自定义指标保留原始名称和单位，明确缺少专用释义，不猜测健康阈值。

「冻结整个看板」或「设置历史时间」将所有图表的结束时刻统一。个人看板仍可使用自己的回看时长，切换节点或展开更多图表也保持结束时刻。历史模式停止图表实时更新，图表显示历史标识；告警、节点状态和运维总览仍是当前信息，从问题定位图表会返回实时。固定的是查询范围，重新查询可能读到后来补齐的历史样本。

放大图表可单独选择或前后平移时段，查看各维度的末行值、最小值、最大值、均值及非空采样数量。「对比上一时段」比较同节点、同图表、同单位的相邻等长时段，按维度 ID 配对并展示均值、差值和相对变化率。前段均值为 0 或负数时只展示差值；缺失、非有限值、溢出或单位不一致会明确处理，不将缺失值补成 0。

图表 CSV 导出当前已加载的各维度数值；对比 CSV 包含两段 UTC 边界、单位、统计值、采样数量及不可计算原因。堆叠图使用各维度自身数值，文本字段进行 CSV 与公式转义，不包含令牌。

均值使用接口已返回有限采样的算术平均，长时间范围可能经过聚合。两段实际采样网格或数据覆盖不同，会影响可比性；非空采样比例不是业务可用率，上升或下降也不自动代表健康变好或变坏。历史保留不足与请求失败有明确提示；切换时段、关闭对比或进入后台会取消对应请求，过期响应不回填。
