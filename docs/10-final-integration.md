# 性能与发布收尾更新

2026-09-23，本次整合最新 Web 看板、运维工作台与服务端性能优化，作为这一轮开发的交付版本。源码默认版本继续使用 `2.0.0-dev`；GitHub 安装包沿用现有自动递增标签规则，具体发布状态以对应提交的 Release 工作流为准。

## 本次整合

- 进程列表读取最近一次完整快照，避免等待慢速系统采样；返回实际采样时间。取消采样不推进 CPU/I/O 基线、图表和快照，恢复后保持正确的速率区间。
- 保留主线的 5 秒进程 I/O 采样节流；被取消的采样不消耗更新周期，下次到期仍可立即重试。
- Top 进程查询只保留所需数量的候选；TSDB 按查询时间窗口复制样本；有序异常历史使用二分定位，时间回拨时回退扫描。
- 只查询异常率时跳过原始指标聚合，继续沿用相同的时间网格、权限与分层参数校验。历史基准、测试方法及限制见 [验收记录](05-acceptance.md)。
- 保留最新主线的 54 个看板样板、个人看板选择性导入、草稿恢复、统一历史窗口、相邻时段对比和 CSV 导出；使用说明见 [Web 看板更新](09-dashboard-final-update.md)。
- 统一验收与 CI 增加运维记录重启持久化、macOS 进程身份及快照检查。macOS 客户端打包必须签名并验证成功；Linux 发布环境补齐安全存储插件的 `libsecret` 构建依赖，运行依赖同时补入 README 和 Release 说明。

## 升级与交付

默认认证保持开启，首次部署生成独立随机密码，已有数据目录继续沿用原密码。不要用新的空数据目录替代正在使用的数据目录，也不要将密码或实际配置加入分发包。

升级前停止服务并保留原二进制与数据备份；使用新二进制和原配置、原数据目录启动，核对登录、历史曲线、进程采样时间以及运维问题记录。运维记录存储升级后的降级限制见 [2.0 说明](06-monitor-2.0.md)，TSDB 备份和恢复约束见 [验收记录](05-acceptance.md)。

本机服务端归档包含已内嵌 Web 的 `monitord`、示例配置、README 和 `plugins.d`，不含部署密码或采集数据。归档旁的清单记录源码提交、构建版本、二进制与归档 SHA-256，便于核对。双仓库同步须分别确认 GitHub、GitLab 的 `main` 都指向交付提交；代码推送和安装包发布是两个独立结果。

## 验证范围

本轮在 Intel macOS 使用 Go 1.27.1、Node 24.19.0、Flutter 3.35.4 验证，测试服务使用临时配置、数据目录和空闲本机端口。

- Web 生产构建及类型检查、完整 Go vet 和 race 测试通过。
- 浏览器共 116 项桌面/手机宽度用例完成验证：初跑 113 项通过，3 项桌面用例超时。两处多标签页测试增加真实的前台切换，未改断言和超时；对这 3 项用例的桌面/手机范围定向复测 6 项全部通过。节点切换用例无需代码调整即可通过复测。
- Flutter 静态检查无问题，65 项测试全部通过。
- 默认认证、未授权 WebSocket 拒绝、重启和密码重置、崩溃恢复、备份恢复、运维记录重启持久化通过。
- macOS 进程身份、退出清理与快照时间核对通过；启动和稳定采集失败数均为 0。
- 10/100/1000 个模拟节点的 Hub 写入与重启历史核对通过。这是本机 HTTP 合成数据，不代表 1000 台真实 Agent。
- 120 秒本机持续采集：83 张图、60 次查询、错误 0；查询中位数 5.20 ms，最大 RSS 18.75 MiB。测试期间有其他构建负载，且只启用脚本规定的采集器，不能外推为所有部署的占用或性能承诺。
- 服务端 8 个目标交叉编译通过；跨平台编译不等于对应平台运行或设备验收。

本轮不替代 72 小时稳定性测试、生产数据量验证、手机真机验证或开发者证书签名与公证。
