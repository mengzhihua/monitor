# 手机 H5 看板

手机 H5 与桌面 Web 共用 Vue Dashboard、登录、权限和 API。页面在窄屏自动切换布局，打包后内嵌在 `monitord`，无需单独部署前端服务。

## 访问与升级

1. 使用包含本更新的服务端发布包升级，或从仓库根目录运行 `make all`，先构建 Web 再编译 Go。只运行 `make core` 不会更新页面。
2. 在手机浏览器打开已有监控地址，例如 `https://monitor.example.com/`，将示例域名替换为实际服务地址。局域网可使用手机可达的服务器 IP 和监听端口（默认 `19999`）；`localhost` 指向当前手机。
3. 使用已有密码或身份认证登录。首次部署的随机密码仍在服务器 `<data_dir>/web-password` 中，不会因手机访问改变。

远程访问沿用项目的 HTTPS 反向代理或可信加密网络要求。不要将真实密码放入书签、分享链接或主屏幕 URL。此更新不修改现有服务器的监听地址、防火墙或代理配置。

## 手机操作

| 入口 | 用途 |
| --- | --- |
| 总览 | 查看节点健康、资源、新鲜度与问题，按已有角色处理问题 |
| 图表 | 筛选指标、选择时间跨度、跳转分组、查看历史和个人看板 |
| 告警 | 独立查看当前节点告警与事件日志；长名称、来源图表及持续时间在卡片中换行展示 |
| 更多 | 服务与拓扑、规则、日志及其他已有工具；配置仅管理员可见，退出登录也在这里 |

Hub 顶部仍可切换节点；所选节点刷新后保留。手机“更多”以弹层打开，支持关闭、点击背景和 Escape；打开时聚焦关闭按钮，支持键盘切换工具，关闭后焦点返回触发按钮。

手机图表提供可选择维度的读数，展示**当前已加载数据最后一行**的值和时间，不需要鼠标悬停。最后一行缺失时显示“缺失”，不以旧值填补；历史模式显示所选历史数据的末行，聚合查询同时标明采样步长，不能把聚合值当作原始瞬时值。放大图表在窄屏使用全屏详情，可查历史、统计、对比及导出。

表单和主要触控按钮适配手机尺寸；长表格只在各自容器内滚动。底部导航和全屏详情预留设备安全区，页面保留浏览器缩放能力。告警静默、关闭及规则修改仍受服务端原有角色和节点限制。

## 添加到主屏幕

- iPhone / iPad：在 Safari 共享菜单选择“添加到主屏幕”。
- Android：在浏览器菜单选择“添加到主屏幕”或“安装应用”，以浏览器提供的选项为准。
- 页面提供独立图标、应用名称和 `standalone` 显示声明；浏览器决定实际安装及启动形式。相关平台行为见 [Apple Web App 配置说明](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html)和 [Web Manifest display](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Manifest/Reference/display)。

默认入口为 `/?view=operations`；也可收藏 `/?view=charts` 或 `/?view=alarms`。Manifest 和快捷方式均不包含凭据。认证仍使用会话存储，主屏幕独立窗口或关闭后重新进入可能需要再次登录。退出会结束当前登录并清除会话凭据。

本更新没有注册 Service Worker、没有新增离线业务数据缓存或 Web Push。静态主屏幕入口不代表离线监控：图表、告警、日志及处置均需要服务器连接。切到后台沿用已有暂停轮询和恢复机制，不能依靠后台网页持续报警。

## 验证范围

2026-10-09 本地验证：`make all`、前端类型检查及 `verify-default-auth.py` 通过；Chrome 专项与回归合计覆盖 258 个有效浏览器用例（14 个按平台条件跳过）。旧配置入口及手机悬停读数用例已适配新导航/触控操作并复验通过。检查了手机图表、告警、服务及桌面截图；本更新没有修改服务端业务逻辑。

浏览器用例使用隔离配置、临时数据和测试账号，覆盖 320、390、430 像素宽度及桌面布局：导航、弹层键盘交互、登录退出与权限、长节点名、图表读数与历史、告警和服务卡片、Manifest/图标及无离线缓存。复现时先构建嵌入式服务端：

```bash
make all
cd web
npm run test:e2e
```

本地 Chrome 可设置 `MONITOR_BROWSER_CHANNEL=chrome`，隔离端口可设置 `MONITOR_E2E_PORT`。自动化手机尺寸验证不等同于真实 iPhone Safari、Android 主屏幕安装或软键盘实机验收；这些仍需在实际部署地址和设备上确认。
