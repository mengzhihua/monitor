# AI 问题解决与人工复核

此更新按“AI 生成修复方案，用户逐步处理并复核”的方式工作。沿用[个人模型配置](17-ai-analysis.md)，桌面 Web 与手机 H5 共用同一入口和记录。

## 从问题开始

1. 在 **运维总览 → 当前问题 → AI 解决问题** 打开，自动选择问题所在节点、图表与方案模式。也可以打开 **AI 分析 → 生成修复方案**，自行选择指标并描述问题。
2. **生成本地预览**，核对统计、时间跨度和缺失情况。具体问题绑定当前告警阶段；问题恢复、升级或重新触发后，旧问题入口会要求重新选择。生成预览不联系模型。
3. 点击 **发送快照并生成方案**。服务端要求模型返回结构化 JSON，验证后保存到当前账号的工作台。最多 5 个可能原因和 8 个步骤，必须含复核步骤；修复建议必须有风险和回退说明，指标引用必须来自已核对的快照。
4. 核对每一步的适用环境、指令、预期结果、风险及回退方法，在实际系统中人工处理。填写 **待处理 / 已人工完成 / 不适用或跳过** 和备注，点击 **保存此步记录**。编辑不自动保存，处理状态不改变真实告警或执行系统命令。
5. 等待新的采样后点击 **重新采样并复核**，核对相同长度窗口的前后指标及关联告警状态。可下载包含已保存步骤、备注、事实快照和最近一次复核的文本报告。

开启面板时读取当前节点的方案列表，可在其他浏览器或手机选择已有方案继续处理。勾选“查看全部节点的个人方案”可查看、下载或删除已移除节点的旧方案，释放个人存储名额；这些方案无法对已不存在的节点继续采样。普通指标分析仍可独立使用。方案记录属于当前登录身份，即使未配置模型也可读取自己的已存方案、记录步骤和复核。

## 复核含义

复核由服务端重新读取最初选择的节点、图表和时间窗口，不再次调用模型；每次只保留最近一份复核。前后比较的是桶均值的平均，窗口可能重叠。数字变化不是修复操作具有因果效果的证明，数据缺失也不补零。

| 结果 | 含义 |
| --- | --- |
| 已取得新数据，请人工核对效果 | 一般问题已有新的可读指标，系统不判断业务问题是否解决 |
| 关联告警当前已恢复 | 同图表、同名称告警的新鲜求值为 CLEAR；不保证根因已经解决 |
| 关联告警仍在触发 | 当前仍是原阶段的 WARNING 或 CRITICAL |
| 告警已进入新阶段 | 告警升级、恢复后重新触发等导致阶段 ID 改变，需要重新评估 |
| 尚无处理后的新采样 | 最新采集或告警求值未晚于方案快照，请等待新采样后再复核 |
| 数据不足或过期 | 节点/采集/告警状态过期、没有有效指标或关联告警不可确认，无法判断效果 |

图表新鲜度使用实际最近一次采集时间，允许窗口为 `max(30 秒, 3 × 采集间隔)`；远端节点必须在线。告警新鲜度使用最近求值时间，允许窗口为 `max(30 秒, 3 × 告警周期)`；远端记录没有周期时使用 30 秒，本机健康引擎需启用。此时间独立于历史聚合桶的结束时间，不使用最近有效历史值冒充新的采样。节点身份变化、原图表删除或权限变化会阻止复核。

## 记录、安全与资源

- 按登录身份隔离，同凭据共享记录，同名不同凭据不共享；静态凭据轮换后进入新的个人空间。匿名和分享链接不能使用该工作台。
- 只读账号可以保存自己的方案与人工步骤记录，不能因此获得系统修改权限。服务器在读取、更新、删除及复核时检查方案所属账号与节点机房权限。
- 方案文件为 `<data_dir>/operations/ai-resolutions.json`，Unix 权限为 `0600`，原子替换，重启保留。文件含用户问题、模型方案、事实快照、人工备注和最近复核，未做额外静态加密；部署目录、Windows ACL 与备份需按运维数据管理。此文件不会从模型配置复制 API Key 或监控登录凭据。
- 人工备注、步骤状态和复核结果不会自动发给模型、工单系统或通知通道。生成方案的模型请求仍只包含用户问题及已核对的监控快照；方案名称、指令及报告均以纯文本展示。
- 结构化方案最多 16 KiB；每账号最多 10 份、全服务最多 256 份方案，文件最大 16 MiB。满额时先下载并删除旧方案；没有自动清理。删除只移除当前存储记录，不移除已下载报告或管理员备份。
- 并发修改检查版本，冲突时保留页面草稿；读取最新版本后展示服务端记录供核对，再手动保存。取消保存、复核或删除只能取消等待，服务器可能已完成操作，界面要求先读取最新版本。
- 方案生成沿用每身份 1 个、全服务 2 个模型调用和 60 秒超时。复核沿用每身份 1 个、全服务 2 个历史查询限制，不新增轮询、自动模型重试或修复执行器。读取采集时间不复制整张图表的数值映射。

模型返回不完整 JSON、未知字段、重复步骤、没有复核步骤、缺少必要回退或引用未选指标时，会提示生成失败并拒绝保存。请重新生成预览再尝试；系统不会自动重试产生额外调用。存储故障可能发生在模型已完成之后，应先恢复数据目录；原子替换后目录同步失败会暂停该存储，重启重读磁盘后恢复，避免覆盖已提交版本。

## 验证方式与边界

```bash
make all
make test
python3 scripts/verify-ai-analysis.py
cd web
npm run test:e2e -- ai-analysis.spec.ts ai-resolution.spec.ts
```

Go 验证覆盖结构化格式与范围、身份和机房权限、版本冲突、私有文件、重启/删除、存储容量与同步失败、冻结快照、JSON 转义密钥脱敏和真实告警阶段绑定。运行验收使用真实 `monitord`、本机 RAM 采集和本地模拟模型，验证生成、步骤、复核与重启，检查人工备注不发给模型。浏览器专项覆盖桌面/手机、明确发送、从问题进入、草稿冲突、取消后读取最新版本、跨面板继续处理、报告下载与 320 像素布局。

尚未用用户真实模型凭据调用外部服务，也未在用户实际服务器上执行方案或验证业务修复；Chrome 手机尺寸测试不代表真实 Safari/Android 软键盘验收。模型格式兼容和修复指令的环境适用性需在自己的部署中核对。
